# VR Creeper — Minecraft 6DoF

Браузерна 3D-сцена на A-Frame. Minecraft-пейзаж генерується кодом, модель кріпера взята з AR-проєкту. Картка `card.jpg` та `targets.mind` для VR не потрібні.

## Запуск через GitHub Pages

1. Створити публічний GitHub-репозиторій.
2. Завантажити `index.html` у корінь репозиторію та `assets/creeper.glb` у папку `assets`.
3. **Settings → Pages → Build and deployment → Deploy from a branch**. Вибрати гілку `main`, папку `/(root)` та зберегти.
4. Відкрити адресу `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/` та натиснути **ЗАПУСТИТИ**.

Під час запуску потрібен інтернет для A-Frame CDN. WebXR/VR-кнопка з'являється лише за наявності сумісного браузера та обладнання; в інших браузерах працює звичайний 3D-режим.

## Керування

| 6DoF | Клавіші |
|---|---|
| Вперед / назад (X) | W / S |
| Ліворуч / праворуч (Y) | A / D |
| Вгору / вниз (Z) | Пробіл / Shift |
| Pitch | Стрілки ↑ / ↓ |
| Yaw | Стрілки ← / → |
| Roll | Q / E |
| Перемкнути 1-шу / 3-тю особу | V або кнопка |
| Скинути Pitch і Roll | R |
| Огляд | Перетягування мишею / пальцем |

Логічна система координат ТЗ (X вперед, Y праворуч, Z вгору) конвертується в координати Three.js (X праворуч, Y вгору, −Z вперед).
