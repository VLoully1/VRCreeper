# VR Creeper — Енергія порталу

Навчальний проєкт віртуальної 3D-сцени Minecraft-стилю на A-Frame 1.6.0 з 6DoF.

## Ідея гри

Зібрати **6 енергокристалів** у 3D-світі, облітаючи дерева і пагорби, а потім дістатися фіолетового порталу. Портал активується лише після збору всіх кристалів. Є підказка напряму/відстані, лічильник та екран перемоги.

## Керування

- `W/S` — вперед/назад
- `A/D` — ліворуч/праворуч
- `Space/Shift` — вгору/вниз (вільний політ)
- `↑/↓` — Pitch
- `←/→` — Yaw
- `Q/E` — Roll
- Утримання лівої кнопки миші + рух — огляд
- `V` — від першої / третьої особи
- `R` — скинути Pitch і Roll
- «Почати заново» — перезапуск місії

## Колізії

- Тверда поверхня ландшафту; під землю не пройти.
- Стовбури й крони дерев з блоків — тверді перешкоди.
- Рамка порталу — тверда, всередині прохід.
- Межі світу. При упорі у перешкоду доступне ковзання вздовж неї.
- Режим 6DoF — вільний політ, без гравітації. Висоту треба контролювати вручну.

## Публікація на GitHub Pages

Якщо репозиторій уже існує, **замінити лише `index.html`** і не чіпати `assets/creeper.glb`.

Для нового репозиторію завантажити `index.html` і всю папку `assets` у корінь репозиторію. Далі `Settings → Pages → Deploy from a branch → main → /(root) → Save`.

Для відтворення роботи потрібен доступ до A-Frame CDN при завантаженні сторінки. Проєкт працює як браузерна 3D-сцена; повноцінне VR-управління контролерами шолома тут не реалізовано.
